# PROGRESSION_DESIGN — 성취감 시스템 설계

---

## 배경 및 필요성

현재 게임의 성취 구조는 **점수 갱신**과 **아이템 획득**에 한정되어 있다.  
플레이를 반복해도 "나"가 성장하는 느낌이 없으며, 장기 리텐션을 유지할 동인이 부족하다.

```
현재: 점프 → 점수 오름 → 죽음 → 재시작 (루프만 반복)
목표: 점프 → 점수 오름 → 죽음 → "다음엔 더 강해진 나로 재시작"
```

레벨 시스템은 게임 구조를 지나치게 복잡하게 만들 수 있으므로 제외.  
미션 시스템은 추후 개발 예정 — 그 전 단계로 아래 세 가지 방향을 검토한다.

---

## 1안: 영구 패시브 업그레이드

### 개요

코인을 소비해 **게임 전반에 영구적으로 적용되는 능력치**를 올리는 방식.  
플레이할수록 코인이 쌓이고, 코인으로 실제로 게임이 편해지는 선순환 구조.

> 상세 업그레이드 목록 및 가격은 [`SHOP_DESIGN.md > 영구 업그레이드`](./SHOP_DESIGN.md) 참고.

### 핵심 업그레이드 항목

| 업그레이드 | 효과 | 최대 단계 |
|-----------|------|-----------|
| 🧲 자석 지속시간 | 3초 → 5초 → 8초 → 12초 | 3단계 |
| ⭐ 로켓 지속시간 | 3초 → 4초 → 5초 | 2단계 |
| 🪙 코인 획득 배율 | ×1 → ×1.2 → ×1.5 → ×2 | 3단계 |
| 🛡 방어막 내구도 | 1회 → 2회 → 3회 | 2단계 |
| 💨 착지 판정 범위 | 기본 → +10% → +20% | 2단계 |

### 설계 원칙

- 단계를 **유한**하게 제한해 "완성"의 느낌을 제공한다 (무한 업그레이드 지양)
- 모든 업그레이드는 밸런스에 **적당한 수준의 영향**만 주어야 한다 (P2W 방지)
- 코인 상점의 기존 "영구 업그레이드" 탭에서 구매 가능

### 유저 경험 흐름

```
플레이 → 코인 획득 → 업그레이드 구매 → 같은 플레이가 더 편해짐
                                         → 더 높은 마일스톤 달성 가능
                                         → 더 많은 코인 획득 (선순환)
```

### 구현 포인트

- `SaveManager`에 각 업그레이드 단계 저장 필드 추가
- `MagnetSystem`, `ShieldSystem`, `ScoreSystem` 등 해당 시스템에 단계별 수치 참조 로직 추가
- 상점 "업그레이드" 탭 UI에 단계 표시 및 구매 버튼 연결

## 2안: 마일스톤 해금 시스템

### 개요

특정 목표를 달성하면 **새 콘텐츠가 잠금 해제**되는 방식.  
"조금만 더 하면 뭔가 열린다"는 강력한 플레이 동기를 제공하며, 추후 미션 시스템의 전 단계로 자연스럽게 연결된다.

### 마일스톤 목록 (안)

> 점수 스케일 기준 (2026-08-27): 착지당 평균 ≈ 1.8점, 착지 50회 ≈ 90점, 착지 100회 ≈ 180점.
> 아래 수치는 이 스케일 기반 추정치이며, 플레이테스트 후 재조정 필요.

| 달성 조건 | 해금 내용 | 성격 | 난이도 기준 |
|-----------|-----------|------|------------|
| 누적 점프 100회 | 자석 업그레이드 슬롯 해금 | 기능 해금 | 약 5~10판 |
| 최고 점수 20 달성 | 신규 스킨 1종 해금 | 보상 | 입문 (~10회 착지) |
| 최고 점수 60 달성 | 신규 배경 테마 해금 | 시각 변화 | 익숙함 (~30회 착지) |
| 코인 500개 누적 획득 | 방어막 업그레이드 슬롯 해금 | 기능 해금 | 약 20~30판 누적 |
| 누적 점프 500회 | 특별 스킨 1종 해금 | 보상 | 약 30~50판 |
| 최고 점수 120 달성 | 고급 업그레이드 슬롯 해금 | 기능 해금 | 실력 있음 (~60회 착지) |
| 룰렛 10회 이용 | 전용 코인 보너스 아이템 해금 | 행동 보상 | 꾸준한 플레이 |

> 마일스톤 목록과 수치는 플레이테스트 후 조정 필요.

### 설계 원칙

- 조건은 **누적형** (리셋 불가)으로 설계해 장기 플레이를 유도
- 해금 순간은 **팡파레 연출**로 도파민 자극 (화면 전체 이펙트 + 효과음)
- 목표까지 남은 진행도를 언제든 확인 가능한 UI 제공 (목표 뱃지 or 프로그레스 바)
- 1안(영구 업그레이드)과 연계: 마일스톤으로 업그레이드 슬롯을 해금하고, 코인으로 업그레이드 구매

### 유저 경험 흐름

```
플레이 → 마일스톤 진행도 누적
       → 달성 시 해금 연출 (팡파레)
       → 새 스킨/업그레이드 슬롯 획득
       → 다음 마일스톤 목표 자동 표시
```

### 구현 포인트

- `SaveManager`에 누적 통계 저장 (totalJumps, lifetimeCoins 등 — 일부 이미 존재)
- `MilestoneManager` 신규 생성: 달성 조건 체크 + 해금 처리 + 달성 내역 저장
- 마일스톤 달성 시 오버레이 연출 (Phaser 이벤트로 트리거)
- 타이틀 또는 결과 화면에 "달성 목표" 뷰 추가

## 3안: 콤보 시스템 + 코인 배율

### 개요

연속으로 착지에 성공할수록 **코인 획득량이 폭발적으로 늘어나는** 방식.  
순간순간의 작은 성취감을 제공하고, 숙련도가 직접 보상으로 이어진다.

### 콤보 단계

| 연속 착지 횟수 | 코인 배율 | 연출 |
|--------------|-----------|------|
| 1~2회 (기본) | ×1 | 기본 |
| 3회 | ×2 | 착지 시 숫자 강조 표시 |
| 5회 | ×3 | 글로우 이펙트 + 효과음 |
| 10회 | ×5 | 화면 연출 + 특별 효과음 |
| 20회 이상 | ×8 | 풀 화면 이펙트 |

> 콤보는 **착지 실패(낙사) 시 리셋**.  
> 구름을 밟지 않고 공중에서만 있는 시간이 길어지면 리셋할 지 여부는 밸런스 검토 필요.

### 설계 원칙

- 콤보 수는 HUD에 상시 표시 (숫자 + 아이콘)
- 고콤보일수록 배경이나 캐릭터에 시각적 변화를 주어 "지금 잘하고 있다"는 피드백 강조
- 높은 콤보를 유지하면 결과 화면에서 "최고 콤보: N" 별도 기록 표시
- 점수 자체가 아닌 **코인 배율만** 증가 (최고점수 리더보드 공정성 유지)

### 구현 포인트

- `ScoreSystem`에 `comboCount`, `maxCombo` 필드 추가
- 착지 성공 시 콤보 증가, 낙사 시 콤보 리셋
- `ScoreSystem.onLand()` 에서 코인 배율 계산 후 `SaveManager.addCoins()` 호출
- HUD에 콤보 카운터 추가 (`GameHud.updateCombo()`)
- 결과 화면(`ResultPanel`)에 최고 콤보 표시

## 추천 조합: 1안 + 2안

세 가지 안은 독립적이지만, **1안과 2안을 조합**하면 가장 강력한 리텐션 구조가 된다.

```
마일스톤 달성 (2안)
    ↓ 업그레이드 슬롯 해금
코인 모으기 (3안 콤보로 촉진 가능)
    ↓ 해금된 슬롯 업그레이드 구매 (1안)
더 강해진 캐릭터로 더 높은 마일스톤 도전
    ↓ 선순환
```

플레이어는 동시에 두 가지 목표를 갖게 된다:
1. **마일스톤 달성** — 점수/점프 목표 (실력 성장)
2. **코인 모아 업그레이드** — 리소스 누적 (캐릭터 성장)

3안(콤보)은 선택적으로 도입해 "숙련 플레이어에게 보너스"를 주는 레이어로 활용.
