# SHOP_DESIGN — 안 떨어질개: 상점 시스템 설계

---

## 기본 방향

- **수익화 모델**: 광고(AdMob) + 인앱구매(IAP) 혼합
- **재화**: 코인 1종 (소프트) + 실제 돈 (IAP)
- **P2W 방지**: 밸런스에 영향을 주는 업그레이드는 최소한으로 단계 제한

---

## 재화 시스템

### 코인 (소프트 커런시)

| 획득 방법 | 수량 |
|-----------|------|
| 게임 종료 시 점수 1점 | = 코인 1개 |
| 결과 화면에서 광고 시청 | 획득 코인 ×3 |
| 일일 첫 플레이 보너스 | +30코인 |

> **밸런스 기준**: 무과금 유저가 2~3주 캐주얼 플레이로 코인 스킨 1개를 살 수 있어야 한다.

---

## 상점 카테고리

### 1. 스킨 (Cosmetics)

게임 밸런스에 영향 없는 외형 변경. 핵심 수익원.

| 스킨 | 획득 방법 | 가격 |
|------|-----------|------|
| 갈색 강아지 (기본) | 기본 제공 | 무료 |
| 골든 리트리버 | 코인 | 500코인 |
| 달마시안 | 코인 | 800코인 |
| 흑백 보더콜리 | 코인 | 800코인 |
| 웰시코기 | 코인 | 1,200코인 |
| 고양이 | 코인 | 1,500코인 |
| 우주복 강아지 🚀 | IAP | $1.99 |
| 천사 강아지 👼 | IAP | $1.99 |
| 마법사 강아지 🧙 | IAP | $2.99 |

> **고양이 추가 이유**: 강아지 게임에 고양이를 넣으면 유저가 공유한다. 밈 요소 = 자발적 홍보.

---

### 2. 패시브 슬롯

게임 시작 전 선택하는 지속 효과. 기본 슬롯 1개, 슬롯 2개로 확장 가능.

#### 슬롯 확장

| 슬롯 | 상태 | 가격 |
|------|------|------|
| 슬롯 1 | 기본 제공 | 무료 |
| 슬롯 2 | IAP 또는 코인 | $1.99 또는 2,500코인 |

> **밸런스 메모**: 로켓은 인게임 자동 발동이라 슬롯과 무관. 슬롯 2의 체감은 "로켓 종료 후 귀환 시 방어막이 남아있음" 정도로 파괴적 수준은 아님.

#### 선택 가능한 패시브 목록

| 패시브 | 효과 | 구현 상태 |
|--------|------|-----------|
| 🫧 방어막 | 번개 충돌 1회 무효, 비눗방울 비주얼 | ✅ 구현 완료 |
| 🦅 더블 점프 | 공중에서 1회 추가 점프 가능, 착지 시 리셋 | 미구현 |
| 💫 구름 소환 | 쿨타임마다 발 아래 임시 구름 소환 (수초 후 낙하) | 미구현 |

---

### 3. 부스터 (1회성 소모품)

게임 시작 전 최대 1개 선택. 코인 소모 또는 광고 시청으로 획득.

| 부스터 | 효과 | 코인 가격 | 구현 기반 |
|--------|------|-----------|-----------|
| ⚡ 초기 부스터 | 게임 시작 시 방어막 1개 추가 지급 | 30코인 | `ShieldSystem.activate()` |
| 🛡️ 장애물 방패 | 첫 번째 장애물 피해 자동 무효 1회 | 40코인 | 신규 로직 |
| 🌟 점수 2배 | 1게임 동안 점수 ×2 (최고점수 갱신 제외) | 50코인 | `ScoreSystem` multiplier 추가 |
| 🧲 자석 효과 | 일정 시간 착지 판정 범위 확대 (구름 덜 빗나감) | 40코인 | `LAND_TOLERANCE_Y` 임시 확대 |
| ⏱️ 타임 슬로우 | 3초간 게임 전체 절반 속도 | 60코인 | `scene.time.timeScale = 0.5` |
| 🧊 구름 동결 | 4초간 모든 구름 궤도 이동 정지 | 50코인 | `orbitSpeed` 임시 0 |
| 🎺 새떼 퇴치 나팔 | 현재 새떼 즉시 소멸 + 일정 시간 새떼 스폰 억제 | 45코인 | `ObstacleSystem.clearAll()` + 타이머 지연 |

> **점수 2배가 최고점수에서 제외되는 이유**: 과금 유저가 리더보드를 독식하면 무과금 유저가 이탈한다. 별도 "부스터 점수"로 성취감은 살림.

---

### 4. 부활 (광고 / 아이템)

추락으로 게임오버 발생 시 팝업을 띄워 부활 방법 선택. 게임 시작 전에 선택하는 것이 아니라, 게임오버 순간 소비.

#### 팝업 흐름

```
추락 → 게임오버 감지
    └── 부활 팝업 표시 (1게임 1회 한정)
        ├── [광고 보고 부활]  → AdMob 광고 시청 후 부활 (무료)
        ├── [아이템 사용 부활] → 부활 아이템 1개 소비 (코인 구매 또는 IAP)
        └── [포기]            → 결과 화면으로 이동
```

#### 부활 처리 방식

- 가장 가까운 구름 위로 순간이동 + 방어막 1개 지급
- 1게임 1회로 제한 (광고·아이템 모두 해당)
- 부활 후 최고점수 갱신 허용 여부는 추후 밸런스 검토

#### 부활 아이템 가격

| 상품 | 가격 |
|------|------|
| 부활 아이템 1개 | 80코인 |
| 부활 아이템 3개 | 200코인 |
| 부활 아이템 (IAP) | $0.99 / 3개 |

---

### 5. 영구 업그레이드

한 번 구매하면 영원히 적용. 단계를 제한해 "완성"의 느낌을 줌.

| 업그레이드 | 효과 | 단계 | 코인 |
|-----------|------|------|------|
| 🫧 방어막 강화 | 방어 횟수 +1 (최대 2회) | 1단계 끝 | 1,000코인 |
| 🚀 로켓 시간 연장 | 지속시간 +1초 (3초→4초) | 1단계 끝 | 800코인 |
| ⭐ 별 등장률 증가 (1) | 별 스폰 주기 단축 (N→N-1 구름) | 1단계 | 600코인 |
| ⭐ 별 등장률 증가 (2) | 추가 단축 | 2단계 끝 | 1,200코인 |

> **단계 제한 이유**: 무한 업그레이드가 가능하면 과금 유저가 게임을 너무 쉽게 만들어 흥미를 잃는다.

### 6. IAP 패키지

| 상품 | 내용 | 가격 |
|------|------|------|
| 광고 제거 | 영구 광고 없음 | $2.99 |
| 코인 소 | 코인 300개 | $0.99 |
| 코인 중 | 코인 800개 (+60 보너스) | $1.99 |

> **스타터 팩**: 신규 유저 전용 1회 한정으로 표시. 타이틀 화면 첫 진입 시 강조 노출.

## 상점 진입 동선 (UX)

```
타이틀 화면
├── [플레이] → 조작 패턴 + 패시브 슬롯 + 부스터 선택 화면
│              └── 게임 시작
│                  ├── 인게임: 추락 → 부활 팝업
│                  │           ├── 광고 보고 부활
│                  │           ├── 아이템 사용 부활
│                  │           └── 포기 → 결과 화면
│                  └── 결과 화면 → [광고 보고 코인 3배]
└── [상점] 버튼
    ├── 스킨 탭
    ├── 패시브 탭 (슬롯 선택 + 슬롯 확장 구매)
    ├── 부스터 탭
    ├── 업그레이드 탭
    └── 코인/프리미엄 탭
```

## 구현 우선순위

| 우선순위 | 항목 | 이유 |
|----------|------|------|
| **P0** | 코인 획득 시스템 (점수 → 코인) | 상점 전체의 기반 |
| **P0** | 코인 UI (HUD 표시 + localStorage 저장) | 없으면 상점 의미 없음 |
| **P1** | 스킨 상점 + 스킨 전환 렌더링 | 핵심 수익원 |
| **P1** | 부활 팝업 (광고 or 아이템) | 광고 수익 + 유저 이탈 방지 효과 큼 |
| **P1** | 점수 2배 부스터 | 구현 쉽고 구매 유도 즉각적 |
| **P2** | 자석·구름 동결·타임 슬로우 부스터 | 기존 코드 재활용, 체감 임팩트 큼 |
| **P2** | 더블 점프·구름 소환 패시브 | 신규 시스템 추가 필요 |
| **P2** | 영구 업그레이드 | 장기 유저 리텐션 |
| **P2** | 광고 제거 IAP | 광고 연동 후 구현 |
| **P3** | 패시브 슬롯 확장 | 패시브 콘텐츠 충분해진 이후 |
| **P3** | 새떼 퇴치 나팔 | 장애물 시스템 안정화 이후 |
