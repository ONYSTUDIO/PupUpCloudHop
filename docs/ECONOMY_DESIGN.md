## 1. 설계 원칙

1. **판 안의 성능은 팔지 않는다.** 점수는 실력의 기록이다. 인게임 아이템(별·자석·동결·타임슬로우)은 판 중 무료 픽업으로만 존재한다.
2. **돈과 시간은 "다시 할 기회"와 "모으는 재미"에 쓰게 한다.** 부활, 외형 수집이 핵심 싱크다.
3. **수익의 주력은 보상형 광고, IAP는 물건을 직접 판다.** 중간 재화(다이아) 없이 가격이 곧 상품이다.
4. **시작 전 마찰을 없앤다.** 죽으면 바로 다시. 판 시작 전 선택 화면은 "로켓 출발(광고)" 버튼 하나만.

## 4. 부활·출석·룰렛

### 부활 (1판 1회)
```
추락 → 부활 팝업
    ├── [광고 보고 부활]    무료, 기본 선택지
    ├── [부활권 사용 🎟️]    보유 시 표시
    └── [포기]              결과 화면
```
- 가장 가까운 구름 위로 순간이동 + 방어막 1개 (기존 규칙 유지)
- 코인으로는 부활하지 않는다 (광고 부활 수익 보호)
- 광고 제거 구매자: 광고 부활 버튼이 광고 없이 바로 부활로 바뀜 (1판 1회 그대로)
- 🎟️ 획득처: 출석 7일차, 룰렛(4% 확률), 주간 미션(3번째 완료 시), 스타터 팩, IAP 부활권 팩
  - 출석 5일차는 🧩조각 10개로 변경됨 (2026-10-20)

### 룰렛
- 무료 1회/일 + 광고 시청 2회/일. **유료 스핀 없음**
- 보상: 코인(대부분), 조각(중간), 부활권(희귀)
- 유상 구매로 돌리는 경로가 없어 확률형 아이템 규제 부담이 크게 줄어든다. 단, 보상 확률표는 게임 내에 공개해 두는 것을 권장 (출시 전 최신 규정 확인)

#### 룰렛 6슬롯 보상 테이블 ✅ 확정 (2026-10-26)

| 슬롯 | 보상 | 확률 |
|------|------|------|
| 1 | 🪙30 | 30% |
| 2 | 🪙60 | 24% |
| 3 | 🧩 조각 14개 | 20% |
| 4 | 🪙100 | 14% |
| 5 | 🪙150 | 8% |
| 6 | 🎟️ 부활권 1 | 4% |

**확률 합계 검증**: 30+24+20+14+8+4 = 100%

**1회 기댓값 계산**:
- 코인: 30×0.30 + 60×0.24 + 100×0.14 + 150×0.08 = 9.0 + 14.4 + 14.0 + 12.0 = **🪙49.4**
- 조각: 14×0.20 = **🧩2.8**
- 부활권: 4% 확률 → 25회에 1번 꼴

> 설계 포인트: 조각 슬롯 3개(🧩5/10/15)를 🧩14 단일 슬롯으로 병합, 최고 코인 🪙200→🪙150으로 조정. 기댓값 🪙47.3 → 🪙49.4 소폭 증가.

### 5-2. 영구 업그레이드 (✅ 4종, 코인+조각 병행 — 2026-10-20 확정)

| 업그레이드 | 효과 | 1단계 비용 | 2단계 비용 | 해금 조건 |
|-----------|------|-----------|-----------|-----------|
| ⭐ 로켓 지속시간 | 3초 → 4초 → 5초 | 🪙1,500 + 🧩20 | 🪙3,000 + 🧩40 | 기본 |

- 자석 기본 지속시간은 GAME_RULES 기준 10초로 통일

### 구현 영향 (코드 저장소 미연결, 문서 기준 추정)
- `TopHud`: 💎 다이아 표시 제거 (UI_ARCHITECTURE의 HUD 1)
- `SaveManager` / localStorage `pup_up_save`: 다이아 필드 제거, 방어막·자석 수량 필드 제거, 부활권 유지
- Supabase `profiles`: 다이아 컬럼 제거, `player_inventory` 는 부활권만
- 부활 팝업: 💎3 분기 제거, 광고 부활 버튼 활성화 (AdMob 연동과 함께)
- 룰렛: 유료 스핀·`roulette_state` 의 유료 스핀 횟수 → 광고 스핀 횟수로 의미 변경
- 상점: 부스터 탭·패시브 탭 제거, 스킨 탭 → 컬렉션 탭(스킨·테마·이펙트)
- 게임 시작 전 선택 화면: 패시브·부스터 선택 제거, 로켓 출발 버튼만
- 출시 전이므로 기존 유저 다이아 보상 이관은 불필요 (테스트 계정만 정리)
