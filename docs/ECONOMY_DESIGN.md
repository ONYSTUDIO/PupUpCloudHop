## 1. 설계 원칙

1. **판 안의 성능은 팔지 않는다.** 점수는 실력의 기록이다. 인게임 아이템(별·자석·동결·타임슬로우)은 판 중 무료 픽업으로만 존재한다.
2. **돈과 시간은 "다시 할 기회"와 "모으는 재미"에 쓰게 한다.** 부활, 외형 수집이 핵심 싱크다.
3. **수익의 주력은 보상형 광고, IAP는 물건을 직접 판다.** 중간 재화(다이아) 없이 가격이 곧 상품이다.
4. **시작 전 마찰을 없앤다.** 죽으면 바로 다시. 판 시작 전 선택 화면은 "로켓 출발(광고)" 버튼 하나만.

## 3. 코인 획득

| 경로 | 수량 | 조건 | 상태 |
|------|------|------|------|
| 점수 → 코인 | 1점 = 🪙1 | 매 판 | 유지 |
| 인-런 마일스톤 | 착지 10/25/50/100회 → 🪙10/25/60/150 | 매 판 자동 | 유지 (RETENTION) |
| BIG JUMP / AMAZING | +🪙2 / +🪙4 | 매 판 자동 | 유지 (RETENTION) |
| 결과 화면 광고 | 이번 판 코인 **×2** | 1판 1회 | 🟡 ×3 → ×2 |
| 일일 첫 플레이 | +🪙30 | 하루 1회 | 유지 |
| 출석 | 7일 주기 (4장) | 하루 1회 | 7일차 보상 변경 |
| 일일 미션 | 3개, 총 🪙55 | 매일 리셋 | 유지 (RETENTION) |
| 고정 미션 | 총 🪙2,200 | 1회성 | 유지 (BALANCE) |
| 룰렛 | 🪙30~500 | 무료 1회 + 광고 2회/일 | 유료 스핀 삭제 |
| IAP 코인팩 | 6장 참고 | — | 가격 재책정 |

> ×3 → ×2 이유: 광고는 매 판 보게 하는 게 수익에 좋다. 대신 1회당 보상을 낮춰 코인 인플레를 막는다.

## 4. 부활·출석·룰렛

### 부활 (1판 1회)
```
추락 → 부활 팝업
    ├── [광고 보고 부활]    무료, 기본 선택지
    ├── [부활권 사용 🎟️]    보유 시 표시
    └── [포기]              결과 화면
```
- 가장 가까운 구름 위로 순간이동 + 방어막 1개 (기존 규칙 유지)
- 코인으로는 부활하지 않는다 (광고 부활 수익 보호)
- 광고 제거 구매자: 광고 부활 버튼이 광고 없이 바로 부활로 바뀜 (1판 1회 그대로)
- 🎟️ 획득처: 출석 5일차, 출석 7일차, 룰렛, 주간 미션, 스타터 팩, IAP 부활권 팩

### 출석 7일 주기
| 일차 | 보상 | 변경 |
|------|------|------|
| 1 | 🪙30 | |
| 2 | 🪙50 | |
| 3 | 🪙80 | 🧲 자석 아이템 → 코인 (자석 인벤토리 삭제) |
| 4 | 🪙80 | |
| 5 | 🎟️ 부활권 1 | |
| 6 | 🪙100 | |
| 7 | 🎟️ 부활권 1 + 🪙200 🎉 | 💎3 → 부활권 + 코인 |

### 룰렛
- 무료 1회/일 + 광고 시청 2회/일. **유료 스핀 없음**
- 보상: 코인(대부분), 부활권(가끔), 한정 외형(희귀)
- 유상 구매로 돌리는 경로가 없어 확률형 아이템 규제 부담이 크게 줄어든다. 단, 보상 확률표는 게임 내에 공개해 두는 것을 권장 (출시 전 최신 규정 확인)

## 5. 코인 사용처

### 5-1. 외형 수집 (메인 싱크)
| 등급 | 코인 가격 | 무과금 도달 기간 (5-3 기준) | 예시 |
|------|----------|------------------------|------|
| 일반 | 🪙1,000 | 약 2일 | 스카프 색, 고글 색, 착지 이펙트 |
| 레어 | 🪙2,500 | 약 5~6일 | 골든 리트리버, 달마시안, 보더콜리, 구름섬 테마 |
| 에픽 | 🪙5,000 | 약 11일 | 웰시코기 변형, 고양이, 배경 테마, 점프 트레일 |
| 프리미엄 | 현금 전용 | — | 우주복·천사·마법사 강아지 |

- 출시 시 목표 수량: 코인 외형 20종 이상, 전체 합계 약 🪙50,000. 업그레이드 🪙20,000 포함 시 무과금 약 5개월분
- 상점 상단에 컬렉션 달성률 표시: `컬렉션 7 / 24`
- 마일스톤 해금 외형(PROGRESSION 2안)은 코인 없이 달성 보상으로 지급

### 5-2. 영구 업그레이드 (🟡 4종으로 축소, 단계 유한)
| 업그레이드 | 효과 | 1단계 | 2단계 | 3단계 | 해금 조건 |
|-----------|------|-------|-------|-------|-----------|
| ⭐ 로켓 지속시간 | 3초 → 4초 → 5초 | 🪙1,500 | 🪙3,000 | — | 기본 |
| ✨ 아이템 등장률 | 픽업 간격 −10% → −20% | 🪙1,500 | 🪙3,000 | — | 누적 점프 100회 |
| 🪙 코인 배율 | ×1 → ×1.2 → ×1.5 | 🪙2,000 | 🪙4,000 | — | 코인 500 누적 |
| 🫧 시작 방어막 | 없음 → 판 시작 시 방어막 1개 | 🪙5,000 | — | — | 최고 점수 60 |

- 합계 🪙20,000. 전 단계 완료 시 "업그레이드 완성" 뱃지
- 자석 지속시간·착지 판정 범위·방어막 내구도는 삭제: 착지 판정을 영구로 넓히면 기록의 의미가 흐려진다
- 자석 기본 지속시간은 GAME_RULES 기준 10초로 통일

### 5-3. 무과금 월 수입 시뮬레이션 (하루 4판, 평균 25점 가정)
| 항목 | 하루 | 월(30일) |
|------|------|---------|
| 점수 → 코인 (4판 × 25) | 100 | 3,000 |
| 인-런 마일스톤 + BIG JUMP (판당 ~14) | 56 | 1,680 |
| 결과 광고 ×2 (4판 중 2판 시청) | 50 | 1,500 |
| 일일 첫 플레이 | 30 | 900 |
| 출석 (주 540 / 7) | ~77 | ~2,310 |
| 일일 미션 | 55 | 1,650 |
| 룰렛 (3회, 기대값 ~30) | ~90 | ~2,700 |
| **합계** | **~458** | **~13,740** |

> 고정 미션 🪙2,200 은 첫 2~3주에 추가로 들어온다.
> 룰렛 비중이 크므로 룰렛 보상표는 1회 기대값을 🪙30 안팎으로 잡는다 (60이면 월 수입이 약 20% 늘어난다).
> 기존 목표 "코인 스킨 1개 2~3주"는 레어 1개 ≈ 1주 이내로 앞당겼다. 첫 구매를 빨리 경험시키고, 긴 꼬리는 컬렉션 수량으로 만든다.

### 구현 영향 (코드 저장소 미연결, 문서 기준 추정)
- `TopHud`: 💎 다이아 표시 제거 (UI_ARCHITECTURE의 HUD 1)

- 부활 팝업: 💎3 분기 제거, 광고 부활 버튼 활성화 (AdMob 연동과 함께)
