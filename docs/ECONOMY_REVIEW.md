## 3. 왜 "아이템 사서 쓰기"가 약하게 느껴지는가

1. **무료 픽업과 겹친다.** 자석·동결·타임슬로우는 판 중에 공짜로 떨어진다. 같은 효과를 돈 주고 미리 사는 이유가 약하다.
2. **효과 대비 판이 짧다.** 1판 1~3분, 효과는 8~10초. 사서 켜도 체감이 작고, 다음 판엔 다시 사야 한다.
3. **점수가 곧 실력 표현이다.** Space Dog 류 게임의 재미는 "내 손으로 세운 최고 기록"이다. 사서 올린 점수는 기록 가치를 깎는다(그래서 점수 2배를 최고점에서 빼는 예외 규칙까지 생겼다).
4. **시작 전 선택 단계가 원터치 흐름을 끊는다.** 하이퍼 캐주얼은 "죽자마자 다시"가 핵심인데, 패시브+부스터 선택 화면이 매 판 마찰이 된다.
5. **카테고리가 너무 많다.** 같은 효과가 최대 5군데에 있어 유저도 개발자도 헷갈린다.

결론: 이 장르에서 돈과 시간을 쓰게 만드는 건 **"다시 할 기회(부활)"와 "모으는 재미(외형 수집)"**이고, 판 성능을 사는 소모품은 비중을 낮추는 게 맞다.

## 4. 개편 방향 (추천안)

### 4-1. 재화: 코인 1종 + 현금 직접 결제 (다이아 제거) — 추천

- 다이아의 사용처는 부활 💎3, 룰렛, 코인 교환 셋뿐이고, 부활은 광고로 대체하는 게 광고 수익에도 유리하다.
- 1인 개발에서 재화 2종은 밸런스 표·교환비·패키지 역산을 두 배로 관리해야 한다(위 불일치 대부분이 다이아 쪽).
- **유료 재화로 돌리는 룰렛은 확률형 아이템**이라, 국내 출시 시 게임산업법에 따라 확률 공개 의무가 생긴다. 룰렛을 광고·무료 전용으로 두면 이 부담이 사라진다.
- IAP는 재화가 아니라 **물건을 직접 판다**: 광고 제거, 프리미엄 스킨, 스타터 팩, 코인팩(소량).

> 대안(다이아 유지)을 택한다면: 다이아 사용처를 "프리미엄 스킨 + 부활"로 좁히고, 룰렛 유료 스핀·코인 교환은 삭제, 무료 다이아는 월 10~20으로 실제 제한.

### 4-2. 아이템 정리

| 현재 | 개편 후 |
|------|--------|
| 인게임 픽업 (별·자석·동결·타임슬로우) | **유지.** 판 안의 재미 요소로만 존재, 판매하지 않음 |
| 부스터 7종 (코인 구매) | **삭제.** 대신 "로켓 출발"(시작 시 로켓 3초) 1종을 **판 시작 전 보상형 광고**로 제공 |
| 패시브 슬롯 + 슬롯 확장 | **삭제.** 방어막·자석 효과는 영구 업그레이드로 흡수 |
| 인벤토리 (방어막·자석·부활) | **부활권 1종만 유지.** 출석·미션·룰렛 보상과 IAP로 획득 |
| 영구 업그레이드 6종 | **3~4종으로 축소, 단계 유한 유지** (로켓 지속, 아이템 등장률, 코인 배율, 방어막 시작 1회 정도) |

### 4-3. 코인 사용처를 "수집"으로 이동

- 코인의 메인 싱크는 **외형 수집**: 강아지 스킨, 스카프·고글 색, 구름섬 테마, 배경 테마, 착지 이펙트·점프 트레일.
- 현재 코인 스킨 5종(총 4,800코인)은 무과금 기준 3~4주면 다 사버린다. 수집 항목을 20~30개로 늘리거나, 코인 유입(특히 1점=1코인 + 광고 ×3)을 조이거나 둘 중 하나가 필요하다.
- 컬렉션 달성률(예: 7/24)을 상점 상단에 표시하면 RETENTION_DESIGN의 "완성도 표시" 아이디어를 그대로 쓸 수 있다.
