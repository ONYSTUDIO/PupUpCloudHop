# CURRENCY_DESIGN — 안 떨어질개: 재화 시스템 설계

---

## 재화 종류 개요

| 재화 | 심볼 | 성격 | 한 줄 정의 |
|------|------|------|-----------|
| 코인 | 🪙 | 소프트 커런시 | 게임을 잘 하면 자연스럽게 쌓이는 게임 내 화폐 |
| 다이아몬드 | 💎 | 하드 커런시 | 주로 IAP로 구매하는 프리미엄 화폐. 긴급 편의성에 사용 |

> **포지셔닝 원칙**: 코인은 *콘텐츠 접근성*, 다이아몬드는 *편의성과 긴급 사용*에 집중한다.
> 두 재화가 겹치는 영역을 최소화해야 각자의 존재 이유가 살아난다.

## 🪙 코인 (소프트 커런시)

### 획득 경로

| 방법 | 수량 | 조건 |
|------|------|------|
| 게임 종료 시 점수 변환 | 1점 = 🪙1 | 매 게임 |
| 결과 화면에서 광고 시청 | 획득 코인 ×3 | 1게임 1회 |
| 일일 첫 플레이 보너스 | +🪙30 | 하루 1회 |
| 상점에서 IAP 구매 | 패키지별 상이 | — |
| 룰렛 당첨 | 🪙30 ~ 🪙300 (구간별) | 룰렛 추후 개발 |
| 출석 체크 보상 | 🪙10 ~ 🪙100 (누적) | 출석 기능 추후 개발 |
| 업적 달성 보상 | 🪙50 ~ 🪙500 | 미션 기능 추후 개발 |

### 사용처

| 목적 | 비용 |
|------|------|
| 상점 스킨 구매 | 500 ~ 1,500 🪙 |
| 상점 패시브 구매 | 800 ~ 1,200 🪙 |
| 상점 부스터 구매 | 30 ~ 60 🪙 |
| 상점 영구 업그레이드 | 600 ~ 1,200 🪙 |
| 부활 아이템 구매 | 80 🪙 / 1개 · 200 🪙 / 3개 |

> **밸런스 기준**: 무과금 유저가 2~3주 캐주얼 플레이(하루 평균 3~5게임, 평균 점수 20~30점)로
> 코인 스킨 1개(500 🪙)를 살 수 있어야 한다.
> → 하루 평균 수입 60~90 🪙, 10~15일이면 달성 가능.

### 코인 인플레이션 방지

- 상점에 충분한 코인 소모 아이템(부스터, 업그레이드)을 유지해 코인이 쌓이지 않게 한다.
- 영구 업그레이드는 단계 제한을 두어 "다 샀다"는 완성감을 준다.
- 코인 → 다이아몬드 교환은 **불가** (프리미엄 가치 훼손 방지).

## 💎 다이아몬드 (하드 커런시)

### 획득 경로

| 방법 | 수량 | 조건 |
|------|------|------|
| 상점 IAP 구매 | 패키지별 상이 | — |
| 룰렛 당첨 (소량) | 💎1 ~ 💎5 | 룰렛 추후 개발 |
| 광고 시청 보상 | 💎1 ~ 💎2 | 하루 3회 한도 (추후 개발) |
| 출석 7일 연속 달성 | 💎3 | 출석 기능 추후 개발 |
| 업적 달성 보상 (특별) | 💎5 ~ 💎10 | 미션 기능 추후 개발 |

> **설계 의도**: 완전 무과금 유저도 소량의 다이아몬드를 경험할 수 있어야
> 다이아몬드의 가치를 체감하고 IAP 구매를 고려하게 된다.
> 단, 무료 획득량은 월 💎10~20 수준으로 제한해 과금 유인을 유지한다.

### 사용처

| 목적 | 비용 | 비고 |
|------|------|------|
| 룰렛 1회 | 💎5 | 추후 개발 |
| 게임 종료 시 부활 | 회차별 누진 | 아래 부활 비용 테이블 참고 |
| 다이아 → 코인 교환 | 💎1 = 🪙150 | 단방향만 허용 |

### 부활 비용 — 누진 소모 테이블

1게임 내 부활 횟수에 따라 소모 다이아몬드가 증가한다. **최대 3회 제한** (광고 부활 없음).

| 회차 | 소모 다이아 | 누적 합계 | 결정 심리 |
|------|-------------|-----------|-----------|
| 1회차 | 💎1 | 💎1 | "거의 공짜, 일단 해보자" → 진입 장벽 최소화 |
| 2회차 | 💎3 | 💎4 | "3배 올랐네, 이 런이 가치 있나?" → 숙고 유도 |
| 3회차 | 💎7 | 💎11 | "7개는 좀 많은데…" → 신중한 럭셔리 결정 |

> **선택 근거 (1 → 3 → 7)**
>
> - 증가 배율이 ×3 → ×2.3으로 **점진 상승**해 심리적으로 납득하기 쉽다.
>   (A안 1→3→5는 ×3→×1.7로 배율이 줄어 어색, B안 1→5→10은 2회차 장벽이 과도)
> - 1게임 풀 부활(💎11) ≈ $0.99 패키지(💎15)의 73% → 한 패키지로 풀 부활 후 잔여 💎4가
>   다음 게임 1회차 부활로 이어져 **재구매 유인**이 자연스럽게 발생한다.
> - 무과금 월 수입 ~💎50 기준: 1회차를 주 2~3번, 2회차는 주 1번, 3회차는 월 1~2번
>   → 희소성 유지, 과금 유인 보존.
>
> **향후 확장 시**: 1 → 3 → 7 → 15 (증분이 2배씩)으로 자연스럽게 이어진다.

### IAP 다이아몬드 패키지

| 상품 | 다이아 | 가격 | 역산 (부활 기준) |
|------|--------|------|-----------------|
| 다이아 소 | 💎15 | $0.99 | 풀 부활 1게임(💎11) + 잔여 💎4 |
| 다이아 중 | 💎40 (+5 보너스) | $1.99 | 풀 부활 4게임 가능 |
| 다이아 대 | 💎100 (+20 보너스) | $4.99 | 풀 부활 10게임 가능 |

> 룰렛 1회(💎5) ≈ $0.33. 가격 대비 체감 가치가 납득 가능한 수준인지 테스트 후 조정.

## 재화 간 관계 정리

```
IAP ──────────────────► 💎 다이아몬드
광고 시청 (하루 3회)──►      │
출석·업적 (소량) ────►       │
룰렛 당첨 (소량) ────►       │
                    ┌────────┴─────────┐
                    ▼                  ▼
               룰렛 사용        부활 사용 (최대 3회)
               (💎5/회)         1회: 💎1
                    │           2회: 💎3
                    │           3회: 💎7
                    ▼ (단방향 교환)
                🪙 코인 (💎1 = 🪙150)
                    │
         ┌──────────┴──────────┐
         ▼                     ▼
    상점 아이템            부스터/업그레이드
    (스킨·패시브)          (소모성·영구)

게임 플레이 → 점수 → 🪙 코인 (1점 = 🪙1)
결과 화면  → 광고 시청 → 코인 ×3
출석·업적   → 🪙 코인 + 💎 소량
룰렛 당첨   → 🪙 코인 or 💎 다이아
```

## 밸런스 가이드라인

### 무과금 유저 시뮬레이션 (월 기준)

| 항목 | 월 수입 |
|------|---------|
| 일일 첫 플레이 보너스 | 🪙900 |
| 게임 플레이 (하루 5게임 × 평균 25점) | 🪙3,750 |
| 광고 시청 코인 ×3 보너스 (하루 1회) | 🪙1,875 |
| 출석 보상 | 🪙300 |
| **월 코인 합계** | **~🪙6,825** |
| 광고 시청 다이아 (하루 1~2회) | 💎30~60 |
| 출석 7일 달성 (월 4회) | 💎12 |
| **월 다이아 합계** | **~💎42~72** |

> 월 다이아 수입으로 룰렛 8~14회 / 부활 4~7회 사용 가능.
> IAP 유도를 위해 "원할 때 언제나" 쓸 수 있는 수준은 아니어야 한다.

### P2W 방지 원칙

- 다이아몬드로 살 수 있는 것: 편의성 (부활, 룰렛 기회)
- 다이아몬드로 살 수 없는 것: 직접적인 점수 향상 아이템
- 리더보드가 생기면, 부스터(점수 2배) 사용 게임은 별도 집계
