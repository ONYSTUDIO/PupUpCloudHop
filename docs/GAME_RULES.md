# Game Rules — 안 떨어질개: 구름섬 점프

## 확정된 기본 룰

### 구름섬 이동
- 각 구름섬은 지정된 중심점(centerX, centerY)을 기준으로 원형 또는 타원형 궤도를 이동한다
- 궤도 반지름(orbitRadiusX, orbitRadiusY), 속도(orbitSpeed), 회전 방향(rotationDirection: 1 | -1)은 섬마다 다르게 설정된다
- 구름섬은 멈추지 않으며, 플레이어가 올라타 있는 동안에도 계속 이동한다
- 플레이어는 올라탄 구름섬과 함께 이동한다

### 점프
- 화면을 한 번 터치하면 플레이어가 점프한다
- 점프 방향은 가장 가까운 위쪽 구름섬을 자동으로 향한다
- 점프 중에는 중력이 적용된다
- 점프 중에는 출발 구름섬의 영향을 받지 않는다 (약 0.3초 이후 재착지 가능)

### 착지 판정
- 플레이어가 **아래 방향으로 떨어지는 중**에만 착지 판정이 발생한다
- 구름섬의 **윗면**에 닿았을 때만 착지로 인정한다
- 옆이나 아랫면에 부딪히면 착지가 되지 않는다
- 착지 시 플레이어는 구름섬 위에 붙어 함께 이동한다

### 점수

착지할 때마다 **점프 높이 비례 점수**를 획득한다.

```
점수 = MIN_SCORE_PER_LAND + round(높이_이득_px / HEIGHT_UNIT × SCORE_PER_LAYER)

상수 (gameplayConfig.ts 기준)
  MIN_SCORE_PER_LAND = 1    -- 최솟값: 어떤 착지든 보장되는 최소 점수
  SCORE_PER_LAYER    = 1    -- 1층(HEIGHT_UNIT) 완벽 점프 시 높이 보너스
  HEIGHT_UNIT        = 310  -- 층간 평균 거리(px), CLOUD_SPACING 평균값 기준
```

| 케이스 | 높이 이득 | 점수 |
|---|---|---|
| 1층 점프 (310 px) | 310 px | 2점 |
| 2층 스킵 (620 px) | 620 px | 3점 |
| 보텍스 수평 착지 (~100 px) | 100 px | 1점 |
| 완전 동일 층 (0 px) | 0 px | 1점 (최솟값) |

- 직전 출발 구름과 동일한 구름에 착지 시 점수 없음 (기존 규칙 유지)
- 하강 착지(낮은 구름으로 이동)도 높이 이득 = 0으로 처리해 최솟값만 지급
- 최고 기록은 localStorage에 저장된다

### 게임 오버
- 플레이어가 화면 아래로 추락하면 게임이 종료된다
- 게임 오버 후 현재 점수와 최고 기록을 표시한다
- 다시 시작 또는 타이틀로 이동할 수 있다

## 아이템 규칙 (확정)

### ⭐️ 별 아이템 — 로켓 모드

- 인게임 중 구름섬 위에 별 아이콘이 자동 스폰됨 (패턴1 구름 2개마다 1개)
- 비행 중 별에 닿으면 즉시 로켓 모드 발동
- 발동 시 3초 동안 직선 고속 비행 (중력 무시, 방향 고정)
- 로켓 모드 중 통과하는 구름섬 1개당 일반 착지와 동일한 점수 공식 적용 (높이 비례)
- 로켓 모드 중 새 무리, 번개 등 모든 디버프를 무적으로 통과
- 3초 종료 후 일반 비행 상태로 복귀 (이후 중력 재적용)
- ScoreHud에 🚀 카운트다운 타이머 표시

### 🫧 방어막 — 비눗방울 보호막

- 게임 시작 전 아이템 선택 화면에서 방어막 아이템 사용 시 활성화
- 캐릭터 주변에 원형 비눗방울 형태의 보호막이 생성된 채로 게임 시작
- **번개 디버프**: 보호막이 1회 막아주고 소멸
- **새 무리 디버프**: 보호막으로 방어 불가 (그대로 적용됨)
- 방어막 소멸 후에는 재사용 불가 (1회성)
- 획득 방법: 룰렛 당첨 / 출석 보상(3일차) / 상점 구매

### 🧲 자석 아이템 — 착지 판정 확대

- 게임 시작 전 아이템 선택 또는 인게임 자석 아이콘 착지 시 발동
- 10초간 착지 Y 허용 범위 3.5배 확대, X 허용 범위 ±60px 추가 확장
- 자기장 링 비주얼 표시 (캐릭터 주변 원형 이펙트)
- ScoreHud에 🧲 카운트다운 타이머 표시
- 인게임 자석 아이콘: 패턴1 구름 3~7개 간격으로 스폰

### ⏱️ 타임슬로우 — 방향 휠 감속

- 인게임 중 모래시계 아이콘 착지 시 자동 발동 (첫 등장: 4번째 구름, 이후 5~10개 간격)
- 8초간 방향 휠 진자 속도를 25%로 감속 (구름·장애물·캐릭터는 정상 속도 유지)
- 화면 보라색 비네트 테두리 + 4 모서리 회전 시계 링 + 부유 틱 마크 파티클
- 방향 화살표 보라색 글로우 + 점선 흐름 애니메이션
- ScoreHud에 ⏱ 카운트다운 + 진행 바 표시

### 🧊 구름 동결 — 모든 구름 일시 정지

- 인게임 중 눈송이 아이콘 착지 시 자동 발동 (첫 등장: 3번째 구름, 이후 4~9개 간격)
- 10초간 모든 구름섬 궤도 이동 정지 → 종료 시 원래 궤도로 복원
- 구름 얼음 오버레이 + 배경 눈보라 파티클 + 화면 프로스트 테두리
- 동결 중 새떼·번개 스폰 타이머도 동결 시간만큼 밀림
- ScoreHud에 🧊 카운트다운 + 진행 바 표시

### 💀 부활

- 추락 후 게임 오버 시 부활 팝업 자동 표시 (1게임 1회 한정)
- **아이템 보유 시**: 부활 아이템 1개 소비 → 무료 부활
- **아이템 없을 시**: 다이아몬드 💎3 소비 → 부활
- 가장 가까운 구름 위로 순간이동 + 방어막 1개 자동 지급
- 1게임 1회 초과 시 부활 팝업 없이 즉시 결과 화면으로 이동
- 광고 시청 부활은 준비 중 (비활성)

## 장애물 규칙 (확정)

### 🐦 새떼 (BIRD_FLOCK)

- 10점 달성 후 첫 스폰 (해금 후 3초 유예)
- 화면 가장자리에서 가로 방향으로 빠르게 날아가며 통과
- 충돌 시 즉시 게임 오버 (방어막으로 방어 불가, 로켓 모드 중 무적)
- 스폰 간격: 8~15초, 첫 등장 10초 후

### ⚡ 번개 폭풍 (LIGHTNING_STORM)

- 30점 달성 후 첫 스폰 (25초 유예)
- 화면에 경고 표시 → 번개 낙하 → 구름섬이 낙하
- 번개 명중 구름에 있으면 게임 오버 (방어막으로 1회 방어 가능, 로켓 모드 중 무적)
- 스폰 간격: 30~60초
