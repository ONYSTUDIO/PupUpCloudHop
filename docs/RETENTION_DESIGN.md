# RETENTION_DESIGN — 리텐션 강화 설계

---

## 배경 및 문제 정의

현재 플레이 루프는 단순 반복이다.

```
현재: 점프 → 점수 오름 → 죽음 → 재시작 (루프만 반복)
목표: 오늘 올 이유 + 이번 판 안에서의 목표 + 장기 완성 목표
```

캐주얼 게임의 리텐션은 **3개의 목표 루프**가 모두 채워져야 유지된다.

| 루프 | 범위 | 현황 | 역할 |
|------|------|------|------|
| 마이크로 루프 | 이번 판 안에서 | ⚠️ 멀티 점프 연출 + 인-런 마일스톤으로 대응 | "이 판을 더 잘해야 하는 이유" |
| 매크로 루프 | 오늘 / 이번 주 | ⚠️ 1회성 미션만 존재 | "오늘 접속해야 하는 이유" |
| 메타 루프 | 장기 목표 | ❌ 미구현 | "이 게임을 계속 해야 하는 이유" |

미션 시스템이 구현되었으나 **1회 클리어 후 매크로 루프가 끊긴다**는 점이 핵심 문제다.

> **콤보 시스템 폐기**: 진자 조작(방향 휠)이 이미 인지 부하를 주는 상황에서 콤보 유지 부담은 스트레스 이중화로 이어진다. 마이크로 루프는 **수동 추적 없이 자동으로 주어지는 보상**으로 대체한다.

## 1. 마이크로 루프 — 인-런 보상 (콤보 대체)

### 1-1. 멀티 점프 시각 연출 (BIG JUMP!)

2개 이상 구름을 건너뛰어 착지 시 자동으로 연출이 터진다. 유저가 추적하거나 유지할 것이 없다.

| 건너뛴 층 수 | 연출 | 코인 보너스 |
|------------|------|-----------|
| 2층 스킵 | "BIG JUMP!" 텍스트 팡파레 + 코인 파티클 | +2 코인 |
| 3층 스킵 | "AMAZING!" + 더 큰 파티클 + 효과음 변화 | +4 코인 |

> 점수는 기존 높이 비례 공식 유지. 연출과 코인 보너스는 점수와 별개로 지급된다.  
> 구현 위치: `ScoreSystem.onLand()` — 높이 이득이 `HEIGHT_UNIT × 2` 이상일 때 트리거.

### 1-2. 인-런 마일스톤 자동 코인 지급

착지 수가 특정 숫자를 넘으면 자동으로 코인이 터진다. HUD 또는 결과 화면에서 달성 여부 확인 가능.

| 착지 수 | 자동 코인 지급 | 연출 |
|--------|-------------|------|
| 10회   | +10 코인 | 작은 팡파레 |
| 25회   | +25 코인 | 중간 팡파레 |
| 50회   | +60 코인 | 큰 팡파레 |
| 100회  | +150 코인 | 풀 화면 연출 |

> 유저가 "지금 몇 콤보?" 를 추적할 필요 없음. 그냥 살아있으면 자동으로 터짐.  
> 결과 화면에 "이번 판 마일스톤: 3개 달성" 표시.  
> 구현 위치: `ScoreSystem.onLand()` — `landingCount` 임계값 도달 시 `SaveManager.addCoins()` 호출.

## 2. 업그레이드 탭 고도화

> 단순 "코인 내고 수치 올리기"는 구매 후 다시 열지 않는다.  
> 업그레이드 탭을 메타 루프의 엔진으로 만들어야 한다.

### 1-1. 업그레이드별 비주얼 변화

수치 상승에 캐릭터 시각 변화를 연결한다. 숫자보다 캐릭터에 쌓이는 것이 보여야 포기를 못 한다.

| 업그레이드 | 단계 | 비주얼 변화 (예시) |
|-----------|------|-------------------|
| 🧲 자석 | 1단계 | 강아지 목에 작은 자석 목걸이 |
| 🧲 자석 | 2단계 | 목걸이가 빛을 발함 |
| 🧲 자석 | MAX | 목걸이에 코인이 달린 이펙트 |
| ⭐ 로켓 | 1단계 | 강아지 등에 작은 배낭 |
| ⭐ 로켓 | MAX | 배낭에 불꽃 이펙트 |

> 구현 난이도가 높다면 업그레이드 카드 배경색 또는 아이콘 테두리 변화로 대체 가능.

### 1-2. 전체 완성도 표시

업그레이드 탭 상단에 달성률을 표시한다.

```
전체 업그레이드 달성률: 4 / 12 (33%) ████░░░░░░░░
```

탭을 닫을 때 저 숫자가 마음에 남아야 한다. 100%를 채우면 특별 칭호 또는 이펙트를 지급한다.

### 1-3. 마일스톤 연동 (기존 PROGRESSION_DESIGN.md 1안+2안 구조 유지)

```
마일스톤 달성 → 업그레이드 슬롯 해금 → 코인으로 업그레이드 구매
```

업그레이드 슬롯이 처음부터 열려있으면 코인을 한 번에 다 써버리고 리텐션이 끊긴다.  
마일스톤 조건을 달성해야만 슬롯이 열리는 구조를 유지한다.

## 2. 일일 챌린지 모드 (최고 우선순위 신규 제안)

### 개요

매일 다른 규칙 조합으로 플레이하는 특별 모드.  
전체 유저가 같은 조건에서 경쟁하는 일일 랭킹을 제공한다.

### 챌린지 규칙 예시

| 챌린지 이름 | 변경 내용 |
|------------|---------|
| 폭풍의 날 | 구름 속도 ×2 |
| 미니 구름 | 구름 크기 50% 축소 |
| 아이템 파티 | 아이템 스폰 주기 절반 |
| 슬로우 모션 | 전체 속도 70% |
| 장애물 러시 | 장애물 등장 주기 절반 |
| 빙하기 | 구름 동결 아이템 없음, 새떼 2배 |

> 날짜 기반 seed로 규칙 조합을 결정하면 서버 없이 모든 유저가 동일한 챌린지를 경험한다.

### 보상 구조

| 달성 조건 | 보상 |
|----------|------|
| 챌린지 1회 완료 (사망 무관) | 🪙30 |
| 챌린지 점수 상위 50% | 🪙50 추가 |
| 챌린지 점수 상위 10% | 💎1 추가 |
| 7일 연속 챌린지 참여 | 💎3 보너스 |

### 설계 원칙

- 매일 자정 초기화 → 내일 다시 와야 한다는 이유 생성
- 기존 패시브·부스터 선택 없이 챌린지 고정 조건으로 진행 (공정성)
- 일일 랭킹은 상위 N명만 표시 (전체 공개 시 하위권 이탈 유발)

### 구현 포인트

- `DailyChallengeSystem` 신규 생성: 날짜 seed → 규칙 조합 결정
- `GameScene` 진입 시 챌린지 모드 플래그 확인 후 파라미터 적용
- `SaveManager`에 `lastChallengeDate`, `challengeStreak` 필드 추가
- 타이틀 화면에 "오늘의 챌린지" 진입 버튼 추가 (FREE 뱃지, 자정 후 갱신 표시)

## 3. 출석 체크 + 연속 플레이 보상

### 개요

매일 게임을 열면 보상을 지급하는 고전적인 리텐션 장치.  
구현이 단순하지만 "하루 빠지면 손해"라는 심리를 만든다.

### 7일 주기 출석 보상표

| 일차 | 보상 |
|------|------|
| 1일 | 🪙30 |
| 2일 | 🪙50 |
| 3일 | 🧲 자석 아이템 1개 |
| 4일 | 🪙80 |
| 5일 | 🔮 부활 아이템 1개 |
| 6일 | 🪙100 |
| 7일 | 💎3 🎉 |

> 7일을 못 채우면 1일부터 재시작. 보상을 점점 좋아지게 설계해 중간 포기를 방지한다.

### 설계 원칙

- 연속 출석이 끊겨도 벌칙은 없음 (단, 7일 완주 보상 재시작)
- 타이틀 화면 첫 진입 시 출석 팝업 자동 표시
- 이미 수령한 날은 아이콘으로만 표시 (재접속 시 재표시 없음)

### 구현 포인트

- `SaveManager`에 `lastAttendanceDate`, `attendanceStreak`, `attendanceDayClaimed[]` 추가
- `AttendancePopup.ts` 신규 생성 (7칸 그리드, 오늘 강조 표시, 수령 버튼)
- 타이틀 진입 시 날짜 체크 → 출석 팝업 트리거
- 메타 UI에 출석 아이콘 추가 (TODO.md에 미구현으로 표시된 4번째 아이콘)

## 4. 미션 시스템 고도화 (반복 루프로 전환)

### 현황 문제

현재 미션은 1회 클리어 후 수령하면 종료된다. 모두 수령하면 매크로 루프가 끊긴다.

### 개선 방향: 3단계 미션 구조

| 구분 | 주기 | 특성 | 예시 |
|------|------|------|------|
| 고정 미션 | 영구 (현재와 동일) | 마일스톤 성격, 1회만 달성 가능 | 착지 100회 달성 |
| 일일 미션 | 매일 자정 리셋 | 쉬운 목표 3개 | 오늘 10회 착지, 오늘 30점 달성 |
| 주간 미션 | 매주 월요일 리셋 | 누적 목표 3개 | 이번 주 총 착지 100회 |

### 일일 미션 예시

| 미션 | 보상 |
|------|------|
| 오늘 착지 10회 | 🪙20 |
| 오늘 점수 20점 달성 | 🪙20 |
| 오늘 아이템 1개 획득 | 🪙15 |

### 주간 미션 예시

| 미션 | 보상 |
|------|------|
| 이번 주 착지 누적 100회 | 🪙150 |
| 이번 주 최고 점수 50점 | 🪙100 |
| 이번 주 챌린지 3회 참여 | 💎1 |

### 구현 포인트

- DB: `player_missions` 테이블에 `mission_type` (daily/weekly/permanent), `last_reset_date` 컬럼 추가
- `MissionService`에 일일/주간 리셋 RPC 추가
- `MissionPopup.ts` 탭 분리 (고정 / 일일 / 주간)
- 미션 팝업 아이콘 수령 뱃지는 일일/주간 미션 기준으로도 갱신

## 순위 시스템 방향 결정

> **결정**: 주간 결산 + 순위별 보상 방식은 폐기. 단순 랭킹 표시만 유지.

| 폐기 | 유지 |
|------|------|
| 주간 결산 보상 (1/2/3위 별도 보상) | 이번 주 베스트 점수 상위 N명 표시 |
| 어뷰징 방지·서버 운영 부담 | 사회적 비교 욕구 충족 (보상 없이도 충분) |

이유: "안떨어질개"는 하드코어 경쟁 게임이 아님. 점수가 1점 고정이 아닌 높이 비례 방식을 유지하므로 한 번의 실력 있는 런이 랭킹에 유의미하게 반영됨.
