# drop-table

1. 대상 확인: 인게임 아이템은 `ITEM_CONFIG` (스폰 간격 MIN/MAX), 룰렛은 `RouletteScene.ts` 와 ECONOMY_DESIGN 의 룰렛 표.
2. 확률표(가중치 → 확률), 1회 기대값(코인 환산), 분산을 계산한다.
3. 몬테카를로(10만 회)로 "N회 안에 특정 보상이 한 번도 안 나올 확률", 연속 꽝 길이 분포를 확인한다. 스크립트는 `scripts/sim/drop.mjs`.
4. 인게임 아이템은 "판당 등장 횟수 기대값"(착지 N회 기준)을 낸다.
5. 천장(pity)이 필요한 구간이 있으면 제안한다. 코드는 수정하지 않는다.
