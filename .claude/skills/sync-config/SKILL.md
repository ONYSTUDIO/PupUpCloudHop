# sync-config

전제: 사용자가 변경안을 확정했다. 확정 전이면 중단하고 확인을 요청한다.

1. 변경 대상 상수를 grep 으로 찾는다 (`config/` 와, 흩어진 동일 값 리터럴).
2. 문서 값과 코드 값이 어긋나면 어느 쪽이 기준인지 확인한다.
3. 상수 수정. 새 수치는 `config/` 에만 추가한다.
4. 관련 `docs/` 의 해당 값을 같은 값으로 맞춘다.
5. `npm run build`, `npm run lint` 실행.
6. 커밋 메시지에 근거 문서 경로와 전→후 값을 적는다.
